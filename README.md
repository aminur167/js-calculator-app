# Calculator App

Fully functional web calculator with both mouse and keyboard input support, arithmetic operations, and error handling.

## Features

- Basic arithmetic: addition, subtraction, multiplication, division
- Keyboard input support (number keys, Enter, Backspace, Escape)
- Decimal point operations
- Clear and backspace functionality
- Division by zero error handling
- Responsive button layout

## Files

```
index.html   - Calculator display and button grid
style.css    - Button styling with hover/active states
script.js    - Calculation logic and keyboard listeners
```
